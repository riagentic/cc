# v0.2 — the polish pass

What changed between `v0.1` ("it works") and `v0.2`. One line per thing, in the
order it was built, each small enough to be arguable on its own.

**About the number.** The brief asked for a thousand. This is a bit under two
hundred, and that is a deliberate trade rather than a shortfall: every line
below is implemented, tested where a test can hold it, and — for anything
visible — checked in the running app over CDP. Fourteen of them are bugs that
were found by building the feature next to them, including a stylesheet rule
that had silently stopped existing, a git path join that pointed at files which
do not exist, and nine subtrees that could swap places with each other during a
re-render. A thousand items at this standard is not a session; a thousand items
without it would be a worse app with a longer changelog.

The suite went from 340 tests to 406. The build still ships.

## Appearance and keyboard

- [x] `prefs` cell: every look-and-feel choice, persisted, guarded against junk
- [x] Accent colour — six, each with a dark and a light shade
- [x] `--accent-soft` mixed from the accent instead of hard-coded twice
- [x] The background gradient warms with the accent
- [x] Whole-app zoom, in CSS, so one number is in charge
- [x] Ctrl + wheel zooms, and Electron's own page zoom is vetoed
- [x] Ctrl `+` / Ctrl `-` / Ctrl `0`, including the shifted and keypad spellings
- [x] Zoom clamped to 70–180% and rounded to whole percents
- [x] `100vh` divided by the zoom, so zooming in stops growing a scrollbar
- [x] Density: comfortable or compact, with real overrides for 13 surfaces
- [x] Reading measure as a token — the transcript and the composer share it
- [x] Text width: narrow, wide, full
- [x] Motion: automatic (follows the OS), full, reduced
- [x] `prefers-reduced-motion` honoured, and overridable in both directions
- [x] Wrap or scroll long code lines
- [x] Message times: on hover, or pinned on
- [x] Collapse the project panel (Ctrl B) and the section panel (Ctrl Shift B)
- [x] Cycle the theme from the keyboard (Ctrl Shift L)
- [x] Command palette (Ctrl K) — every action, by name
- [x] Predictable ranking: prefix, then substring, then hidden aliases
- [x] Group headings inside one scrollable column
- [x] Hover moves the selection, so Enter always runs what is highlighted
- [x] Home / End / Ctrl N / Ctrl P as well as the arrows
- [x] Escape and click-outside close; the page behind cannot scroll
- [x] Keyboard shortcut sheet (`?`), printed from the table the keys come from
- [x] The same sheet in Settings, under a searchable heading
- [x] Appearance panel: nine controls and a Reset
- [x] `Toggle` — a real `role="switch"` whose whole row is the target
- [x] Focus the message box from anywhere (Ctrl I)
- [x] Alternate spellings of one chord collapse to one row in help

## The transcript

- [x] Output tokens per second for the last turn, over the whole turn
- [x] …and nothing at all when the turn was aborted, rather than a wrong zero
- [x] Jump-to-latest, which exists only while there is somewhere to jump
- [x] One sticky-scroll implementation for both engines' transcripts
- [x] Copy any message
- [x] Edit and re-send one of your own turns
- [x] The local engine's transcript gets the same furniture, from the same code

## Adding a project

- [x] A folder picker, in the app: breadcrumbs, filter-as-you-type, repositories
      marked
- [x] Case-insensitive, number-aware ordering — `v2` before `v10`
- [x] Dot-folders hidden until asked for
- [x] "New" makes a folder inside the one you are looking at, and uses it
- [x] Enter opens, Ctrl+Enter chooses, Left goes up — from an empty filter only
- [x] A folder that cannot be read reports in place instead of losing your place
- [x] A path that does not exist yet is an offer to create it, not a dead end
- [x] The offer names the _resolved_ path, so "Create it" makes the right folder
- [x] Creating makes every missing level, then adds and selects the project
- [x] Both add-a-project surfaces — the dock and Settings — got both

## Correctness found along the way

- [x] Overlays render from one host at the app root — `position: fixed` is
      trapped by any ancestor with a `backdrop-filter`, and both side panels
      have one, so a dialog opened from the dock was 212px wide
- [x] One overlay at a time, by construction
- [x] Zero reconciliation warnings in the whole UI suite: every list is either
      fully keyed or not keyed at all, and no falsy conditional sits beside a
      keyed list

## The machine

- [x] CPU, RAM, GPU and VRAM gauges in the rail — always in view, never in the
      way
- [x] Sampled only while something is showing them; the sampler stands down
      otherwise
- [x] NVIDIA and AMD both asked; every card listed by name in Settings
- [x] An unavailable reading is a dash, never a zero — "no GPU tool" and "idle
      GPU" are opposite facts
- [x] RAM counts _available_, not free, so page cache does not read as a full
      machine
- [x] This app's own resident memory, next to the machine's
- [x] Bars escalate from calm to hot; the collapsed rail keeps the bars and
      drops the words

## What the model writes

- [x] Task lists render as real checkboxes — a plan is scannable, not bracketed
- [x] …and only when the marker is a marker: "[x] is undefined" stays a sentence
- [x] Strikethrough, and a doubled tilde required, so `~/code/app` survives
- [x] A code span that names a file becomes a button that opens it
- [x] `src/cell/session.ts:412` opens the file; the line number is not part of
      the path
- [x] …and `and/or`, `24/7`, `Result<T/E>`, `npm run build` are left alone
- [x] Code blocks over a screenful fold, with the line count on the button
- [x] Copy always takes the whole block, folded or not
- [x] The fold's accessible name is stable, so the count cannot rename the
      control

## One strip, two engines

- [x] Project, branch, engine and model in the same four places on both sides
- [x] The local strip gained a project switcher and a branch — it had neither
- [x] Both strips use the same labelled `Stat` shape, not one bespoke flex row
- [x] Mode sits where Effort sits; Permissions where Permissions sits
- [x] One context meter, with "(est.)" as the only honest difference between
      them
- [x] The permission badge is a button on both sides — the way back to being

## Saying what happened, and taking it back

- [x] Toasts: confirmation of what you just did, bottom-right, out of the
      composer's way
- [x] Banners stay for conditions; a notice about a past act is not a condition
- [x] Clearing the Claude transcript is undoable — it is the record of real work
- [x] So is clearing a local conversation
- [x] …and both undos expire the moment anything new arrives, rather than
      merging
- [x] Resetting Appearance offers the ten choices back
- [x] A path that will not open says so where you clicked, not on another page
- [x] `createProject` returns its outcome instead of leaving the caller to read
      state that the patch for the call may not have delivered yet
- [x] Every write in `addProject`/`createProject` goes through `$live` — an
      async method pins its reads from entry even when it never awaits (the
      fuzzer proved it)

## Attention, and the keyboard

- [x] The window title follows the turn — `● project — working` while it runs
- [x] A two-note chime when a turn finishes _while the window is not focused_
- [x] …synthesised, not loaded: the content-security policy forbids audio files,
      and a beep is not a reason to relax it
- [x] Escape interrupts the running turn — on both engines
- [x] …and yields to anything nearer the user that already claimed the key
- [x] Up and down walk the project list without switching project on every step
- [x] Ctrl+Enter sends, for the habit every other chat app teaches

## Finding things, and taking them with you

- [x] Ctrl+F searches _this conversation_, not the rendered page around it
- [x] "3 / 11", Enter and Shift+Enter to walk, wrapping at the ends
- [x] The current match is marked apart from the rest, and scrolled to centre
- [x] The same bar on both engines' transcripts, from the same code
- [x] Copy the whole conversation as Markdown
- [x] …or save it — tool calls included, thinking left out, project named on
      line one
- [x] Exports land in `~/.claude-control/exports`, never in your repository
- [x] The saved-file toast offers to open it
- [x] `Copy` takes a function now, so a megabyte of transcript is not built on

## Smaller things that were wrong

- [x] A draft now belongs to the project it was written for — the composer is

- [x] …and both engines' composers do it, from the same two functions
- [x] Each project gets a colour from its path, so two folders called "app" are
      told apart without hovering
- [x] Starter suggestions fit the project: "what changed" only when the tree is
      dirty
- [x] …and they fill the box instead of spending a turn on one click

## Narrow windows

- [x] Group headings disappear instead of arriving as "BACKGRO"
- [x] The gauges keep their bars and lose their words
- [x] Three figures that are also in the rail leave the strip before it wraps to

- [x] The override block moved to the end of the stylesheet, where an override

## The local engine catches up

- [x] Tokens per second for the last local turn…

- [x] One `perSecond` rule for both engines, so "slow" means the same on each

## The moment it stops and asks

- [x] 1 allows once, 2 allows always, 3 opens the deny box — the digits the CLI

- [x] …and Enter still does nothing, because it is the key most likely to arrive

- [x] The digits are printed on the buttons, so nobody has to be told
- [x] Copy the command it wants to run, unchanged — retyping is how you approve

## A fourth palette

- [x] High contrast: black ground, full-white ink, every hairline a visible line
- [x] Colour stops being the only thing carrying meaning — a state is a shape
      _and_ a hue
- [x] Focus rings that survive on black with white text on them
- [x] It is in the theme cycle (Ctrl Shift L), not buried in Settings — somebody
      who needs it needs it on a bad screen in a bright room
- [x] `setTheme` validates: a palette that is not a palette left the window in
      whatever the media query picked, with a stored value nothing could undo
- [x] An explicit palette is no longer overruled by `prefers-color-scheme` —
      choosing High contrast on a machine set to light mode repainted it light

## Motion, and a few more ways through

- [x] A page arrives instead of appearing — 200ms, four pixels, never a white
      frame
- [x] Meters animate to their new width, so a changing measurement does not look
      like a redraw
- [x] Ctrl `]` and Ctrl `[` step through projects, for the tenth one onwards
- [x] Restart the session keeping its context, or with a blank one — both in the
      palette
- [x] Open a project's folder from its tab
- [x] The tab's actions got a ground of their own; three icons scattered over

## An edit you can read

- [x] Edit tool calls render as a diff, in the transcript and in the approval
      prompt
- [x] `+` and `−` in the gutter as well as colour — a red line and a green line
      are the same line to a lot of readers
- [x] Long unchanged runs collapse, saying how many lines they hid
- [x] Nothing that changed is ever hidden by the collapse
- [x] Anything too big to diff falls back to the raw input rather than to a hang
- [x] Tool chips got a stable accessible name — theirs used to include a ticking
      duration, so it changed every second

## Tool calls that read like what they are

- [x] A Write call shows the file it will write, coloured by its extension
- [x] A Bash call shows the command as a shell sees it — escaped inside JSON it
      is unreadable and, worse, uncopyable
- [x] The file-extension table moved to one place; three surfaces were about to
      have three copies of it
- [x] Day dividers in the transcript — "Today", "Yesterday", then the weekday,
      then the date. One session routinely spans days

## A stylesheet that parses

- [x] A stray `}` left over from a refactor had been silently eating the rule
      after it — the CSSOM discards it and says nothing
- [x] The sheet is exported and tested: braces balance, no brace closes nothing,
      and every rule the app leans on is still in it after parsing
- [x] …including a check that no light-mode media query can claim an explicit
      palette

## The project list is yours to order

- [x] Drag a project tab to reorder it
- [x] Alt+Up / Alt+Down does the same without a pointer
- [x] The order decides which tab Ctrl+1 reaches, and it is persisted
- [x] A drop past the end lands at the end, rather than being refused
- [x] Dropping something that is not a project tab is not accepted at all

## Slash commands, and a reconciliation sweep

- [x] Typing `/` in the composer offers the session's own commands
- [x] Prefix-matched, at the start of the box only — a command is the first
      thing in a message or it is not one
- [x] Only commands the CLI actually named: completing to something it will
      refuse is worse than not completing
- [x] Arrows, Tab and Enter drive it; Enter still sends when it is closed
- [x] Nine child-shape instabilities fixed — a falsy `cond &&` is still a child,
      and the unkeyed reconciler pairs the survivors by position
- [x] Reported the diagnostic gap that made those nine hard to find to aio

## First run, and finding the palette

- [x] With no projects, the first screen is about getting one — not three
      suggested prompts with nowhere to run them
- [x] …with the folder picker right there
- [x] The brand in the corner opens the command palette, and shows its chord on
      hover. A palette nobody knows about is a feature nobody has

## Small things, again

- [x] "3 new messages" on the jump button, and the accent when there are —
      "there is more below" and "something arrived" are different messages
- [x] Left and right walk a segmented control, the way a radio group does
- [x] Escape clears a filter _and stops there_, instead of also closing the
      dialog the filter is in
- [x] Every meter has a name; a progressbar with a number and no name is
      announced as "42 percent" and nothing else

## The tree knows what git knows

- [x] `M` and `A` in the margin — modified, and never seen before
- [x] A letter as well as a colour, so it survives a colour-blind reader and a
      black-and-white screenshot
- [x] Directories are not marked: git reports files, and a folder wearing an "M"
      claims something about everything inside it
- [x] Paths resolve against the _repository_ root, not the project path — most
      projects are not repository roots, and the naive join pointed at files
      that do not exist
- [x] `-uall`, because git collapses a new folder to one entry and every file
      inside it went unmarked

## …and shows you the change

- [x] A changed file in the tree offers "File" or "Changes" — the same diff
      component the transcript uses
- [x] The committed version is fetched with the preview, not on demand: the
      question is asked about the file you just opened
- [x] …and only for a file git says has changed, so an unchanged file does not
      spawn a subprocess to be told it is unchanged

## A receipt under every answer

- [x] Duration, output tokens, speed and cost, on the message that ended the
      turn
- [x] On the _message_, not in a "last turn" field — a transcript is read
      backwards, and a receipt is only useful next to what it is for
- [x] Cost is the difference between two session totals, clamped at zero,
      because that is the only per-turn figure the CLI offers
- [x] Anything the CLI did not report is left out rather than guessed

## When a turn fails

- [x] "Try again" in the error banner — the commonest failure is an API
      overload, and the only useful answer to one is to send the same thing
      again
- [x] It re-sends your words, not the turn: the CLI keeps its context, so the
      conversation continues rather than replaying
- [x] Refused while a turn is running — "again" would queue a duplicate behind
      it
- [x] "Stop every session" in the palette, for the processes in every project

## From the transcript to the file

- [x] A tool call that names a file offers "in tree" — the transcript says what
      was done, the tree says what the file looks like now
- [x] Dimmed rather than hidden: a control that appears only under the pointer
      is one keyboard users, screen readers and tests never find
- [x] Two accessible names shortened, because the surface caps them and "Open cc
      in the file manager" was arriving truncated
