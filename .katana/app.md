# cc - claude control, next gen claude code electron app for ultimate claude code control


## General
- app is build on and uses latest released (even alpha) aio framework
- app provides ultimate control, monitoring and settings for claude codea
- whatever cannot be directly checked (although this is priority) is be approximated, estimted, assumed and determined any other reasonable way



## Features
- app provides ability to use claude code agent for specific project
- app provides ability to select claude code model
- app provides visual information (progres bar of context usage, ie. used and maximum)
- app provides visual information of claude code memory size 
- app provides visual information of claude code activity
- app provides list of all running sub-agents and sub-taks
- user can see details of each running sub-agents and sub-tasks


## UI
- app has pro quality ui, clean and ergonomic


## Main chat page
- page shows chat to chat with claude code 
- page shows active project directory
- page shows active git branch
- page shows active claude model
- page shows progress bar of current context to max context size
- page shows number of running agents
- page shows number of running tasks
- page shows ongoing processing time of the last user request 



## arguments
- app takes folder as first parameter indicating which is a working project folder


## claude code integration
- app utilizes claude code in the background while user sees cc ui interactions 


## app level
- app is production ready
- app is fully functional
- app is next gen claude code with superior UI, itegration and information


## chat
- chat has syntax color for code and code blocks
